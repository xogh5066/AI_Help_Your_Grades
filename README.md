# AI 사용과 대학생 학업 성취도 분석

> **Does AI Help Your Grades?**  
> 생성형 AI 활용과 학기 말 학점(GPA)의 관계를 탐색한 데이터 분석 프로젝트입니다.

## 1. 프로젝트 소개

생성형 AI는 자료 요약, 아이디어 발상, 과제 작성 등 다양한 학습 활동에 활용되고 있습니다. 그렇다면 **AI를 많이 사용하거나 다양한 도구를 활용하는 학생일수록 학점도 높을까요?**

이 프로젝트는 Kaggle에서 제공하는 학생 데이터를 바탕으로 AI 활용 변수, 일반 학습 시간, 학기 전·후 GPA 사이의 상관관계를 분석합니다. Python으로 데이터를 전처리하고, 상관계수 히트맵을 통해 변수 간 관계를 살펴봅니다.

### 주요 분석 질문

- 주간 생성형 AI 사용 시간은 학기 말 GPA와 어떤 관계가 있는가?
- AI 도구의 다양성과 유료 구독 여부는 학기 말 GPA와 관련이 있는가?
- 기존 GPA와 일반 학습 시간은 AI 관련 변수들과 비교해 어떤 관계를 보이는가?
- AI 사용 시간은 체감 의존도 및 일반 학습 시간과 어떻게 연결되는가?
- 프롬프트 엔지니어링 숙련도를 추가하면 어떤 결과가 나타나는가?

## 2. 데이터셋

> 데이터의 수집 방식, 실제 관측 데이터 여부 및 대표성은 원본 데이터셋 설명에서 별도로 확인해야 합니다. 아래 결과는 해당 데이터셋의 탐색적 분석 결과이며, 대학생 전체로 일반화하지 않습니다.

## 4. 분석 과정

### ① 데이터 수집 및 탐색

`opendatasets`로 Kaggle 데이터를 내려받고, `pandas`로 CSV를 불러옵니다. `head()`와 `info()`로 변수 구성, 자료형, 결측값을 확인합니다.

### ② 분석 변수 선택 및 전처리

1차 분석에서는 학생 식별자, 학기 전·후 GPA, AI 사용 시간, AI 도구 수, 유료 구독 여부, 일반 학습 시간, 체감 AI 의존도 등 8개 열을 선택합니다.

유료 구독 여부는 상관관계 분석을 위해 정수형으로 변환합니다.

```python
data['Paid_Subscription'] = data['Paid_Subscription'].astype(int)
```

### ③ 상관관계 분석 및 시각화

`data.corr()`로 수치형 변수 간 피어슨 상관계수를 계산하고, `seaborn.heatmap()`으로 시각화합니다.

### ④ 프롬프트 엔지니어링 숙련도 추가 분석

숙련도 변수를 추가한 9개 열로 상관관계를 다시 살펴봅니다. 다만 원본 코드의 숙련도 인코딩에는 순서 오류가 있어, 해당 변수의 결과는 수정 후 재검증해야 합니다.

## 5. 주요 분석 결과

아래 수치는 **첨부 노트북에 기록된 상관계수**이며, README 작성 과정에서 원본 CSV로 재계산한 값은 아닙니다.

### AI 활용 변수와 학기 말 GPA

| 변수 조합 | 상관계수 | 해석 |
| --- | ---: | --- |
| 주간 AI 사용 시간 ↔ 학기 말 GPA | 0.019 | 선형 상관관계가 매우 약함 |
| AI 도구 수 ↔ 학기 말 GPA | 0.025 | 선형 상관관계가 매우 약함 |
| 유료 구독 여부 ↔ 학기 말 GPA | 0.0055 | 선형 상관관계가 거의 없음 |
| 체감 AI 의존도 ↔ 학기 말 GPA | 0.014 | 선형 상관관계가 매우 약함 |

이 데이터에서는 AI 사용 시간, 도구 수, 유료 구독 여부 및 체감 의존도와 학기 말 GPA 사이에 강한 선형 관계가 관찰되지 않았습니다.

### 기존 성적 및 학습 시간과의 관계

| 변수 조합 | 상관계수 | 해석 |
| --- | ---: | --- |
| 학기 전 GPA ↔ 학기 말 GPA | 0.93 | 강한 양의 상관관계 |
| 일반 학습 시간 ↔ 학기 말 GPA | 0.14 | 약한 양의 상관관계 |
| 주간 AI 사용 시간 ↔ 체감 AI 의존도 | 0.67 | 비교적 강한 양의 상관관계 |
| 주간 AI 사용 시간 ↔ 일반 학습 시간 | -0.16 | 약한 음의 상관관계 |

학기 전 GPA는 학기 말 GPA와 강하게 연결되어 있었고, 일반 학습 시간은 AI 관련 변수들보다 상대적으로 큰 양의 상관계수를 보였습니다. 또한 AI 사용 시간이 많은 학생일수록 체감 의존도가 높고, 일반 학습 시간은 다소 적은 경향이 나타났습니다.

### 프롬프트 엔지니어링 숙련도 분석 시 주의점

노트북에 기록된 숙련도와 학기 말 GPA의 상관계수는 **0.00018**입니다. 그러나 원본 코드는 다음과 같이 숙련도의 순서를 뒤바꾸어 인코딩합니다.

```python
# 원본 노트북의 매핑: 숙련도 순서와 불일치
mapping = {'Beginner': 1, 'Advanced': 2, 'Intermediate': 3}
```

순서형 변수로 분석하려면 다음과 같이 수정한 뒤 상관계수를 다시 계산해야 합니다.

```python
# 수정 권장 매핑
mapping = {'Beginner': 1, 'Intermediate': 2, 'Advanced': 3}
```

따라서 **0.00018을 올바른 숙련도 순서에 따른 최종 결과로 해석하지 않습니다.** 숙련도별 GPA 분포 비교와 스피어만 상관분석도 추가로 검토할 수 있습니다.

## 6. 결론

> **이 데이터셋에서는 AI 사용량·도구 수·유료 구독 여부와 학기 말 GPA 사이의 선형 상관관계가 매우 약했으며, 기존 GPA와 학기 말 GPA 사이에는 강한 양의 상관관계가 나타났습니다.**

이 결과는 AI를 많이 사용한다는 사실만으로 높은 학점을 설명하기 어렵다는 점을 시사합니다. 다만 상관관계 분석만으로 **“AI는 성적 향상에 효과가 없다”** 또는 **“AI가 학습 역량을 대체할 수 없다”**는 인과적 결론을 내릴 수는 없습니다.

또한 현재 분석은 주로 **학기 말 GPA의 수준**을 비교합니다. 실제 성적 증가폭을 분석하려면 `Post_Semester_GPA - Pre_Semester_GPA`를 별도로 계산하고, 기존 성적 등 다른 요인을 고려해야 합니다.

## 8. 분석의 한계 및 개선 방향

- **인과관계 판단의 한계:** 상관계수만으로 AI 사용의 성적 향상 효과를 판단할 수 없습니다.
- **통계적 유의성 미검정:** 현재 노트북은 p-value나 신뢰구간을 제시하지 않으므로, 상관계수가 작다는 이유만으로 통계적으로 유의하지 않다고 단정하지 않습니다.
- **성적 변화량 분석 필요:** 학기 전·후 GPA 차이를 계산해 AI 활용 변수와의 관계를 추가 분석할 수 있습니다.
- **숙련도 인코딩 수정 필요:** 올바른 순서를 적용한 뒤 결과를 재계산해야 합니다.
- **식별자 제외 필요:** `Student_ID`는 의미 있는 설명변수가 아니므로 상관관계 히트맵에서 제외하는 것이 적절합니다.
- **통제변수 확대:** 전공, 학년, AI 활용 목적 등 제외한 변수들을 고려한 추가 분석이 필요합니다.
- **비선형 관계 검토:** 산점도와 집단별 비교를 통해 단순 상관계수가 놓치는 패턴을 살펴볼 수 있습니다.
- **다변량 분석:** 기존 GPA와 일반 학습 시간 등을 함께 고려하는 회귀분석으로 변수 간 관계를 보완할 수 있습니다.
